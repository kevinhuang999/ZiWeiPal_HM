改版要点 · 新旧对照

只动 UI 不动引擎
区域旧版问题 → 新方案
首页表单五个 NumberPicker 直排、视觉松散 → 品牌头 + 单卡表单（历法/生辰/性别三行），生辰一行五组数字，农历时显示自动换算提示「农历五月初一 · 丁卯年」；新增「最近排盘」（先只存 1 条亦可）
盘面布局4×3 平铺 Grid，命宫无空间感 → 经典环抱布局：中宫 2×2 放盘面概要（五行局/命主身主/四柱/顺逆+起运岁），外圈 12 宫按地支方位分布（巳午未申上行、辰…酉、卯…戌、寅丑子亥下行）。这是所有专业排盘软件的通用心智，用户零学习成本
选中反馈仅换边框色 → 选中宫朱砂描边+光晕+底部 Toast 提示三方四正；点宫格即选中，底部主按钮「查看详情」进入
四化展示四化藏在星名后缀 → 宫内星名后缀保留 + 底部四化横条双保险，扫一眼看全生年四化
详情页六张平铺白卡 → 顶部宫位 Hero（大字主星+徽章）+ 主星/辅星/宫位信息/神煞分组卡片，星曜属性默认展示（不再藏开关）
设置页全部平铺无分组 → 三组卡片：真太阳时+出生地 / 排盘口径（四化流派/年柱/闰月/大限/小限收进下拉或次级页）/ 显示开关；每项加副说明
视图切换三个胶囊钮占一整行 → 分段控件，切大限/流年时中宫概要联动显示当前大限段落或流年四化
