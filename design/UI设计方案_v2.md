# ZiWeiPal_HM · UI 改版设计方案 v2「古纸朱砂·环抱」

> 范围：**只动 UI，不动引擎**。配色沿用 2026-09-01 拍板的「古纸朱砂」（`engine/Constants.ets` COLORS 不变），本次重做**布局、组件、信息层级、交互反馈**。
> 高保真稿：`design/index.html`（P1 首页 / P2 命盘 / P3 详情 / P4 设置，盘面数据取自倪师《天纪》例 19 真实命盘）。

---

## 一、设计原则（为什么这么改）

1. **对齐专业排盘软件的通用心智**：文墨天机、问真排盘等全部采用「十二宫环抱中宫」布局——老用户零学习成本，一眼找到命宫/财帛/夫妻。
2. **一屏看清全局**：命盘页从上到下 = 概要卡 → 视图切换 → 十二宫盘面 → 四化横条 → 操作。不再滚动寻找关键信息。
3. **选中即反馈**：点宫格 → 朱砂描边+光晕+Toast 提示三方四正；再点「查看详情」进入。当前版本点了宫格直接跳页，用户来不及看高亮。
4. **表单减负**：首页五个 TextPicker 直排改为单卡三行（历法/生辰/性别），生辰一行展示、点开轮盘修改。

## 二、页面清单与改动点

### P1 首页（Index.ets）

| 现状 | 改为 |
|---|---|
| 标题+设置按钮，无品牌感 | 品牌头：朱砂圆形「紫」Logo + 应用名 + 副标语「斗数纲目 · 排盘对照」；设置入口移到右上角图标钮 |
| 历法/性别胶囊钮 + 年月日时分 5 个 NumberPicker 直排 | 单张表单卡三行：①历法（公历/农历分段控件）②生辰（一行显示「1987年6月1日18时」，点击弹 TextPicker 弹层或行内展开）③性别（男/女分段控件）+ 右侧自动换算提示（农历时显示对应公历/农历，如「农历五月初一 · 丁卯年」） |
| 无历史记录 | 新增「最近排盘」卡（localStorage/Preferences 存最近 1-3 条：日期时辰+性别+命宫地支），点按直达盘面 |
| 底部无说明 | 页脚小字「全程离线 · 数据不出本机」（卖点前置） |

### P2 命盘页（ChartPage.ets）——本次改版核心

**布局：4×3 平铺 Grid → 4×4 环抱布局**

```
巳    午    未    申          ← 顶行（兄弟/命宫/父母/福德，随盘面变）
辰  ┌──────────┐  酉          ← 中宫 2×2：
卯  │  盘面概要  │  戌             朱印 + 五行局 + 命主/身主
寅    丑    子    亥                 四柱干支 + 顺逆行 + 起运岁
```

- 宫格定位函数（按地支，不按 palaceIndex）：
  `row = 巳午未申→0 / 辰酉卯戌→1~2 / 寅丑子亥→3`，具体：巳(0,0) 午(0,1) 未(0,2) 申(0,3) 辰(1,0) 酉(1,3) 卯(2,0) 戌(2,3) 寅(3,0) 丑(3,1) 子(3,2) 亥(3,3)。
- **中宫内容**（chart 数据全部现成）：五行局（大字）、命主·身主、四柱干支一行、大限顺/逆行 + 起运岁、紫微所在宫名。
- **宫格信息密度**：宫名+地支（头部）→ 大限岁段（右上角小字）→ 主星（12px/600，亮度 9px 灰褐缀后）→ 四化徽章（9px 圆角色块：禄朱砂/权黛蓝/科竹青/忌绛紫，替代现在的彩色文字）→ 辅星 9.5px 茶褐 → 命/身右下角小签。
- **选中态**：朱砂 1.5px 描边 + 2.5px 浅朱光晕；三方四正宫黛蓝 1.5px 描边（保留现有 sanFangSiZheng 逻辑）。
- **点击行为**：单击 = 选中（高亮 + Toast「已选中 命宫（午）· 三方四正高亮」）；再点同一宫或点底部「查看命宫详情」= 跳 DetailPage。现在的「点格即跳」保留为双击/二次点击。
- **四化横条**：盘面下方四等分浅色条（巨门禄/太阳权/文曲科/文昌忌样式），生年四化一屏看全；切流年/大限视图时联动换成对应四化。
- **视图切换**：三个胶囊钮 → 分段控件（米褐底、选中白底朱砂字）。流年/大限时年份选择器收进分段控件右侧（`⟲ 2026`小钮，点开弹层），不单独占一整行。

## 三、组件规范（新增到 Constants.ets 的 TOKEN）

字号五档：22 页题 / 17 星名大 / 15 正文 / 12.5 辅助 / 9.5 宫格微注。
其余全部沿用 COLORS 现有 19 色不改。新增仅 2 个软色可并入：`greenSoft:#E8EFE3`（竹青浅底）、`purpleSoft:#F3E3E8`（绛紫浅底）——四化徽章与横条需要。

| 组件 | 规格 |
|---|---|
| 分段控件 | 米褐 `surfaceAlt` 底、12px 圆角、内 padding 4；选中项白底+主色字+700 |
| 四化徽章 | 9px 白字、3px 圆角、padding 0 2.5px，四色实底 |
| 主按钮 | 朱砂底白字、26px 圆角胶囊、高 50、投影 rgba(155,46,35,.28) |
| 次按钮 | 白底 1px 边框、同胶囊 |
| 卡片 | 白底 16px 圆角、投影 0 2 8 rgba(51,48,43,.06)、卡头 4px 朱砂短竖条 |
| 开关行 | 高 52、上细分隔线、朱砂激活态 |
| Toast | 墨底 92% 透明度、白字、19px 圆角、底部 96px 浮现 2s |

## 四、实施清单（按依赖顺序，只动 4 个页面文件 + Constants）

1. `Constants.ets`：追加 `greenSoft / purpleSoft` 两色。
2. `Index.ets`：品牌头 + 表单卡三行 + 农历换算提示 + 最近排盘（Preferences 存 JSON）。
3. `ChartPage.ets`：环抱布局（Grid 4×4 + 中宫跨 2×2）、宫格按地支定位、四化徽章组件、选中/三方四正态、Toast、四化横条、分段控件。
4. `DetailPage.ets`：Hero 卡 + 分组卡 + 属性默认展示、去返回钮。
5. `SettingsPage.ets`：三分组 + 行内值选择（半屏弹层）+ 副说明 + 城市搜索。
6. 走 `真机回归清单.md` 全量核对（布局改动大，重点回归：三方四正高亮、大限/流年联动、导出 Markdown 不受影响）。
